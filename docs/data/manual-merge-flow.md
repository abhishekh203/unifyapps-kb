# Manual Merge Flow

Source: https://www.unifyapps.com/docs/unify-data/manual-merge-flow
Section: data

---

The Manual Merge Flow is a structured process that allows users to review, compare, and resolve records flagged as “potential matches” (possible duplicates) in the UDM. Instead of relying solely on automated rules, this flow introduces human oversight to ensure only true duplicates are merged, preserving data quality and integrity.
