## Overview

Single Sign-On (SSO) lets users log in to many different software systems with a single set of credentials. When SSO is enabled, users can authenticate through their organization's Identity Provider (IdP), streamlining access and enhancing security.

## Benefits of using SSO with UnifyApps

- **Improved User Experience:** Users don't need to remember separate usernames and passwords for UnifyApps and its applications.
- **Enhanced Security:** Logins are managed by your company's IdP, which can enforce security rules like Multi-Factor Authentication (MFA).
- **Simplified User Management:** User provisioning and de-provisioning can be managed centrally at the IdP level.

## SSO Implementation Levels

You can set up SSO in two places in UnifyApps:

1. **Platform Level SSO Configuration** This configures SSO for the entire UnifyApps platform.
2. **Application Level SSO Configuration** This allows you to configure SSO for a specific application package or a standalone application.
