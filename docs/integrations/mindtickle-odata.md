# Mindtickle OData integration | connect with UnifyApps

Source: https://www.unifyapps.com/docs/unify-integrations/mindtickle-odata
Section: integrations

---

Integrating your application with Mindtickle OData enables seamless access to sales readiness and enablement data by allowing you to query and retrieve structured information such as training progress, user performance, and content analytics through standardized OData endpoints, helping organizations automate reporting, gain actionable insights, and streamline sales enablement workflows efficiently.

## Authentication:

Connecting your application with Mindtickle OData allows you to efficiently fetch and manage sales enablement data, including user performance and training insights, through standardized APIs. Before you begin, ensure you have the following information:

- `Connection Name` : Choose a meaningful name for your connection. This name helps you identify the connection within your application or integration settings. It could be something descriptive like "MyAppMindtickleODataIntegration".
- `Service root URL`: Select the service root URL for Reporting API. If your learning site is based in the US then select Prod US URL.
- `Username`: Enter the username for the Mindtickle instance you would like to connect to.
- `Password`: Enter the password for the Mindtickle instance you would like to connect to.

## Actions :

| **Action Name** | **Description** |
|---|---|
| `List coaching sessions` | Lists coaching sessions from Mindtickle OData |
| `List learner module performances` | Lists learner module performances from Mindtickle OData |
| `List missions` | Lists missions from Mindtickle OData |
| `List certification awarded users` | Lists certification awarded users in series from Mindtickle OData |
| `List users` | Lists users from Mindtickle OData |
