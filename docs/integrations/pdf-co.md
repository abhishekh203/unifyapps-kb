PDF.co is an API platform for PDF and document automation, offering tools for data extraction, conversion, and editing. It enables businesses to process PDFs, generate reports, and integrate document workflows seamlessly.

Integrating your application with PDF.co offers powerful tools for generating, editing, and converting PDF files through API. It simplifies document processing with scalable, secure, and highly customizable functionalities.

## Authentication

Before you begin, ensure you have the following:

- `Connection Name`**:** Choose a meaningful name for your connection, like "MyAppPDFIntegration". This helps in identifying the connection within your application or integration settings.
- `API Key`**:** Pdf.co provides API key based method of authentication.

### API Key Based Authentication

1. Sign up or log in to your PDF.co account by visiting the [PDF.co dashboard](https://app.pdf.co/).
2. Navigate to the API Key section in your account settings. You can access it by clicking on your profile icon and selecting '`API Key`' from the dropdown menu.
3. Generate a new API Key by clicking the '`Create New Key`' button. You can optionally add a label or description for easy identification.
4. Copy the generated API Key and securely store it. Treat the API Key with high confidentiality, as it allows access to your PDF.co account.
