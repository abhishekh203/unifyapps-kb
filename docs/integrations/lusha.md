# Lusha

Source: https://www.unifyapps.com/docs/unify-integrations/lusha
Section: integrations

---

Lusha is a B2B contact and company data platform that helps sales, marketing, and recruiting teams find verified emails, phone numbers, and firmographic data. The Lusha connector uses Lusha's REST API to search and enrich contact and company records.

Integrating Lusha enables teams to enrich leads with accurate contact and company data, streamline prospecting workflows, and automate data-driven sales and outreach processes.

## Authentication :

Before you begin, make sure you have the following information:

- `Connection Name`**:** Choose a descriptive name for your connection. This helps you easily identify the connection within your application or integration settings, such as "MyAppLushaIntegration".
- `Authentication Type`**:** API Key

### API Key :

Complete the following steps to connect to Lusha using an API Key:

1. Log in to your`Lusha` account.
2. Navigate to `Settings` and select the `API section`.
3. Copy your `API Key.` If you don't have one yet, generate a new API Key from this section.
4. Enter the API Key when creating the connection in your application.

## Actions:

| **Actions** | **Description** |
|---|---|
| `Enrich companies` | Enriches companies in Lusha |
| `Enrich contacts` | Enriches contacts in Lusha |
| `Get account usage statistics` | Gets account usage statistics from Lusha |
| `Get company industries` | Retrieve list of available industries for company filtering |
| `Get company revenues` | Retrieve list of available revenue ranges for companies |
| `Get company signal options` | Retrieve available signal options for companies including filter options |
| `Get company signals by IDs` | Retrieve signals data for a list of company IDs |
| `Get company sizes` | Retrieve list of available company size ranges |
| `Get contact countries` | Retrieve list of all available countries for contact filtering |
| `Get contact data points` | Retrieve list of available data points for contact filtering |
| `Get contact departments` | Retrieve list of available departments for contact filtering |
| `Get contact seniority levels` | Retrieve list of available seniority levels for contact filtering |
| `Get contact signal options` | Retrieve available signal options for contacts |
| `Get contact signals by IDs` | Retrieve signals data for a list of contact IDs |
| `Search company names` | Search for company names by text |
| `Search company signals` | Search for company signals using identifiers like domain, company name, or ID |
| `Search contact locations` | Search for locations by text for contact filtering |
| `Search contact signals` | Search for contact signals using identifiers like LinkedIn URL, email, or name and company |
| `Search contacts` | Searches contacts in Lusha |
| `Search multiple companies` | Find detailed information for multiple Lusha companies in a single request. |
| `Search multiple contacts` | Enrich multiple contacts in a single Lusha request. |
| `Search single company` | Find detailed information about a single Lusha company using search criteria. |
| `Search single contact` | Find and enrich a single Lusha contact using search criteria. |
