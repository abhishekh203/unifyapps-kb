# LiveRamp connector

Source: https://www.unifyapps.com/docs/unify-integrations/liveramp
Section: integrations

---

LiveRamp helps organizations unify and activate customer data across marketing, advertising, and analytics platforms through a secure identity resolution framework. It connects first-party data from multiple sources into a single, privacy-safe view, enabling more accurate targeting, personalization, and measurement.

### Authentication:

Integrating your application with LiveRamp enables secure identity resolution, audience data onboarding, and cross-platform activation. Before starting, ensure you have the following information:

1. `Connection Name`**:** Choose a meaningful name for your connection. This name helps you identify the connection within your application or integration settings. It could be something descriptive like "MyAppLiveRampIntegration".
2. `Client ID`**:** Enter the Client ID of your LiveRamp application.
3. `Client Secret`**:** Enter the Client secret of your LiveRamp application.

### ACTIONS :

| **Action Name** | **Description** |
|---|---|
| `Add segments to distribution manager` | Add segments to a distribution manager in LiveRamp |
| `Create clean room` | Creates a new clean room environment in LiveRamp |
| `Create distribution manager` | Create a distribution manager in LiveRamp |
| `Create flow run` | Creates a cleanroom flow run in LiveRamp |
| `Create question` | Creates a question in LiveRamp |
| `Delete question` | Delete a question by its ID in LiveRamp |
| `Get flow run status` | Gets the current status of a flow run in LiveRamp |
| `Get question` | Fetch question details by its ID in LiveRamp |
| `Get cleanroom dataset` | Gets a cleanroom dataset by its ID in LiveRamp |
| `List clean rooms` | Lists all clean rooms in LiveRamp |
| `List deliveries` | Fetch a list of deliveries from LiveRamp |
| `List distribution managers` | Fetch a list of distribution managers from LiveRamp |
| `List segments` | Fetch a list of segments from LiveRamp |
| `List datasets` | Lists all cleanroom datasets in LiveRamp |
| `Update clean room` | Updates metadata or configuration settings of an existing clean room in LiveRamp |
