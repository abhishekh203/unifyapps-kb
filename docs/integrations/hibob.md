# HiBob connector

Source: https://www.unifyapps.com/docs/unify-integrations/hibob
Section: integrations

---

HiBob empowers modern organizations to streamline people management by centralizing HR, payroll, performance, and employee engagement processes in one intuitive platform. It offers flexible workflows, automation, and customization to support diverse workforce needs and evolving business goals. With real-time insights, strong compliance features, and seamless integrations, HiBob enables HR teams and leaders to drive better employee experiences and smarter workforce decisions.

## Authentication:

Integrating your application to HiBob allows you to streamline HR processes, synchronize employee data securely, and enhance workforce management through automated and efficient people operations. Before starting, ensure you have the following information:

1. `Connection Name`**:** Choose a meaningful name for your connection. This name helps you identify the connection within your application or integration settings. It could be something descriptive like "MyAppHiBobIntegration".
2. Service user ID: Enter the Service User ID associated with your HiBob account. To create a Service User, please refer to the official [HiBob](https://apidocs.hibob.com/docs/api-service-users#how-to-create-a-new-service-user) documentation.
3. API key: Enter the API key associated with your HiBob account. To create an API key, please refer to the official [HiBob](https://apidocs.hibob.com/docs/api-service-users#how-to-create-a-new-service-user) documentation.
4. **Environment:** Select the environment you want to connect to — Production or Sandbox.

## ACTIONS :

| **Action Name** | **Description** |
|---|---|
| `Create time off request` | Creates a new time off request in HiBob |
| `Delete time off request` | Deletes an existing time off request in HiBob |
| `Get custom table metadata` | Gets metadata for a custom table in HiBob |
| `Get employee balance` | Gets balance for an employee in HiBob |
| `Get employee details` | Gets employee details in HiBob |
| `Get time off request` | Gets an existing time off request in HiBob |
| `List policy type names` | Lists all policy type names in HiBob |
| `List time off request changes` | Lists changes made to time off request in HiBob |
| `Terminate an employee` | Terminates an employee by its ID in HiBob |
| `Upload a file from file content` | Uploads a file from a file content to a specified folder type in HiBob |
| `Upload a file from URL` | Uploads a file from a URL to a specified folder type in HiBob |
