# How to create a new App + first Page

**Goal:** Create a new Web App in the UnifyApps builder and land on a blank page ready to build.
**Applies to:** Q1 and every assignment that starts a new app.

## Steps (verified from screenshots)

1. Left nav → **AI Applications**. The list of existing apps shows (Name, Type, Workspace, Tags, Created By/On…).
2. Top-right → **+ New Application** (purple button).
3. **Pick the app type** (icons across the top): **Web App** · Mobile App · Copilot Chat · Display.
   → For assignments, choose **Web App**.
4. Fill the form:
   - **Name*** — suffix with your name, e.g. `Product Catalog Abhishekh`.
   - **Tags** — e.g. `assignment 1`.
   - **Sub-domain*** — auto-generated from the name (e.g. `product-catalog-abhishekh`); it does NOT auto-correct if you fix a typo in Name later, so check it.
   - **About this application** — optional short description.
   - **Base Variant*** — **Desktop** · Tablet · Mobile → choose **Desktop**.
   - **Workspace** — select if required.
5. Click **Create application** (bottom-right).
6. You land on **"Choose a Template"**:
   - *Start with:* **Blank Page** · Figma Frame · **Data** (auto-scaffold from an object).
   - *Templates:* Listing Page, Analytics Dashboard, Copilot, Enterprise Search, … (13).
   - → For learning/assignments, pick **Blank Page** (build data sources + blocks by hand rather than letting a template hide the mechanics).

## Gotchas
- **Name typo doesn't propagate:** the sub-domain is generated once; if you fix the Name spelling, verify the sub-domain separately.
- The template screen is a separate step *after* create — the app exists before you pick a page template.
- "Data" template auto-builds a table from an object — fast, but skips the hands-on wiring; avoid while learning.
